// ---------- Icono de los avisos (sustituye a los emojis de los mensajes del servidor) ---------- // Deduce el tono por el TEXTO (la primera línea manda): 'error' (falló), 'ok' (hecho), 'aviso' (hecho, pero alguna // parte falló: se nota en las líneas siguientes) o '' (mensaje neutro: sin icono). var AVISO_MALO_ = /^error|no se pudo|no se pudieron|no se encontr|no se ha anotado|no se anot[oó]|no es una ficha|no es v[aá]lido|est[aá] ocupad|bloquead/i; var AVISO_PARCIAL_ = /no se pudo|no se pudieron|no se encontr|no se ha anotado|no se anot[oó]|no es una ficha|no es v[aá]lido|est[aá] ocupad|ya existe|no existe|no tiene los datos/i; var AVISO_BIEN_ = /correcta|correctamente|guardad|actualizad|restaurad|copiad|registrad|eliminad|liberad|cambiado/i; function tonoAviso_(mensaje) { var lineas = String(mensaje === null || mensaje === undefined ?
