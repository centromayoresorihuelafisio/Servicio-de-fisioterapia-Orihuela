Menú Agenda

Gestión rápida de la agenda

  • 📍 Hoy: Lleva automáticamente a la fecha actual en la agenda para evitar la navegación manual
  • 🔍 Buscar Fecha: Selector rápido para navegar a una fecha específica
  • 🗓️ Agenda Semanal: Vista simplificada de las citas de la semana seleccionada

Menú Pacientes

Gestión de los usuarios

  • ✔️ Alta Paciente: Actualiza el estado del usuario en la base de datos y su historia clínica
  • 📋 Valoración: Abre un formulario intuitivo para valorar dolor, capacidad funcional y consumo de analgésicos

Pestañas principales

El trabajo se organiza en tres pestañas en la parte inferior del documento

Base de Datos Maestra

Datos y gestión de los usuarios

Botones interactivos del encabezado:

  • 🔄 Actualizar: Recalcula el triaje para cada usuario, asigna el número de prioridad y reordena la lista automáticamente
  • 🔍 Lupa: Búsqueda avanzada por DNI, teléfono, etc
  • ➕ Nuevo Paciente: Formulario para introducir nuevos usuarios en la base de datos. Al guardar la lista se reordena automáticamente
  • ✏️ Editar: Permite editar datos de un usuario de la base de datos de forma segura
  • 📞 Citas: Programación de citas únicas o múltiples en la agenda
  • 📋 Valoración: Abre el formulario de valoración para el paciente seleccionado y guarda los datos en la pestaña de Valoraciones
  • 📁 Historia Clínica (HC): Genera una HC del usuario seleccionado y un enlace de acceso directo en la columna Historia clínica
🕒

Agenda 2025-2026

Gestión de citas

Organizamos las sesiones en espejo (Lunes/Miércoles y Martes/Jueves). Los viernes son para sesiones únicas y grupos

  • 🔗 Enlazar: Enlaza la HC de un usuario en la agenda (habitualmente automático)
  • ➡️1 Siguiente Cita: Programa automáticamente la siguiente cita (según el patrón) para uno o varios usuarios (control + clic)
  • ➡️2 Doble Cita: Programa las dos siguientes citas . Ideal para programar la semanal completa seleccionando las citas de miércoles y jueves

Valoraciones

Aquí se guardan los datos de valoración

Registros de dolor, capacidad funcional y consumo de analgésicos

  • Flujo: Selecciona usuario (en base de datos o agenda) → Pulsa el icono 📋 → Rellena el formulario
  • Integridad: Los datos se almacenan automáticamente en la pestaña Valoraciones, no escribir a mano en esta pestaña

Mantenimiento y seguridad

🛡️

Protocolos

Buenas prácticas para la estabilidad del sistema

Selección de usuario: El sistema identifica al usuario basándose en la celda activa. Selecciona el nombre antes de pulsar cualquier botón de acción
Integridad: No copies y pegues datos manualmente. Utiliza los botones del menú para garantizar la integridad de automatismos y fórmulas
Altas y Bajas: No elimines filas de datos de usuarios. Usa la función ✔️ Alta Paciente o ✏️ Editar para cambiar su estado a 🕐 Contactará o 🚫 No responde . Borrar filas puede estropear las estadísticas del servicio o romper alguna automatización
Automatización de HC: Al dar citas desde el formulario de citas, la HC se enlaza automáticamenente a la agenda (si el usuario ya tenía una generada). Si la HC se ha generado posteiormente a la cita utiliza 🔗 Enlazar en la pestaña agenda
